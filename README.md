# Kimi — бесплатный ИИ-ассистент

Веб-чат с открытой языковой моделью, запускаемой по требованию в Google Colab. Проект не требует OpenAI API key и не использует платные API.

## Что есть
- отдельный веб-интерфейс Gradio;
- загрузка модели при запуске Colab;
- история чата в интерфейсе;
- сохранение истории в Google Drive (JSONL);
- настраиваемая модель через переменную `MODEL_ID`;
- базовая обработка ошибок и проверка доступности GPU.

## Быстрый запуск
1. Откройте файл `notebooks/Kimi_Colab.ipynb` в GitHub.
2. Нажмите **Open in Colab** (значок/ссылка вверху ноутбука) или загрузите ноутбук в Google Colab вручную.
3. В Colab выберите **Runtime → Change runtime type → T4 GPU**, если доступно.
4. Запускайте ячейки сверху вниз.
5. Разрешите доступ к Google Drive, если хотите сохранять историю между сессиями.
6. В последней ячейке появится временная публичная ссылка на веб-чат.

## Модель
По умолчанию используется `huihui-ai/Qwen2.5-3B-Instruct-abliterated`. Это сторонняя модификация модели; доступность репозитория, лицензия, качество и совместимость могут меняться. Если модель не загружается, задайте `MODEL_ID` в ноутбуке на `Qwen/Qwen2.5-3B-Instruct`.

Небольшая модель выбрана как практичный компромисс для бесплатной GPU-сессии. Это не гарантирует работу на каждом аккаунте Colab: лимиты GPU и длительность сессии определяются Google.

## История
После подключения Google Drive сообщения добавляются в `MyDrive/KimiAssistant/history.jsonl`. Не сохраняйте там пароли, токены или другую секретную информацию. Публичная ссылка Gradio доступна другим людям, пока сессия запущена; не публикуйте её, если чат содержит личные данные.

## Важно
- Бесплатность относится к коду, модели и использованию бесплатного тарифа там, где он доступен; сторонние сервисы могут менять ограничения.
- Ссылка на чат временная и перестанет работать после остановки/сброса Colab.
- Первый запуск скачивает веса модели и может занять время.
- Не загружайте в чат конфиденциальные данные.
- Проверяйте лицензию модели перед коммерческим использованием.
